# Hub walkthrough media

`hub-tour.gif` cycles through four screenshots of the running AgentSCM Hub. The
full-size originals are `hub-workspace.jpg`, `hub-workflow.jpg`,
`hub-evidence.jpg` and `hub-members.jpg`.

The captures use local synthetic forge identities and a synthetic repository.
The run is a real built-in source-path check, not a model review or a deployment.
The UI explicitly separates the recorded result from native landing admission.
No external account, customer repository or model provider is shown.

The animation holds each view for four or five seconds and loops without flashes.
Frames preserve the captured UI; shorter pages are padded to a common canvas.
The still links in the README provide a non-animated alternative and readable
full-size details. No third-party application interface is included.

When refreshing these files, capture the actual Hub, wait for data to load, and
inspect every image for tokens, personal data, private paths and unsupported
claims before publication. Keep the example limitations visible. Do not stage
capture scripts, local credentials, raw browser logs or private test evidence.
